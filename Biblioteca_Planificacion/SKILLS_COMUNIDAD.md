# Skills de la comunidad que reutilizamos

La base incluye **ocho skills seleccionadas de tres repositorios MIT**, con sus referencias y licencias. Los originales se conservan en `Fuentes_Comunidad/`; la skill activa del proyecto es `video-planificacion-retencion`, que los adapta al formato y a nuestro perfil. No se han instalado APIs de publicación, servicios de análisis ni herramientas externas de estos repositorios.

## Qué hemos adaptado y por qué

| Afirmación presente en originales | Criterio local |
| --- | --- |
| Hay que dejar la respuesta para el final | Se puede enseñar el resultado al principio; el interés puede estar en cómo se logra |
| Un pico de retención demuestra que un momento funcionó | Puede indicar interés, repetición o confusión; hay que revisar contenido y contexto |
| Existe un porcentaje universal de retención saludable | Usar referencias comparables del propio canal; sin ellas no inventar un umbral |
| El bajón está siempre en la mitad | Revisar el gráfico real y la estructura de esa pieza |
| Hay que cambiar el estímulo cada X segundos | Probar un ritmo que preserve comprensión y estilo; el intervalo no es una ley |
| El texto nunca puede repetir la voz | Distinguir rótulo creativo de subtítulo accesible |
| Completar el vídeo es el único objetivo del algoritmo | Considerar interés, satisfacción, audiencia, duración y objetivo; las plataformas describen múltiples señales |
| Publicar cada día o usar un sonido en sus primeros días asegura rendimiento | Cadencia y tendencias se deciden con capacidad real y datos; sin garantía de distribución |
| Un vídeo flojo crea una prohibición permanente para el canal | Formular una hipótesis y buscar contraejemplos; no establecer una regla por una sola pieza |
| Cada checkpoint requiere aprobación | Continuar dentro del encargo autorizado; preguntar solo si falta una decisión necesaria |

Estas correcciones están conectadas con [las fuentes primarias y sus límites](../.agents/skills/video-planificacion-retencion/references/fuentes.md). No se alteraron los originales para esconder sus supuestos.
