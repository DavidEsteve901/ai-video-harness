# Collage por capas

Lee el plan y [la receta de collage](../../../Biblioteca_Estilos_IA/02_RECETAS_ESTILOS.md). Representa una sola idea con pocos elementos reconocibles; define qué se acumula, qué lo transforma y cómo se conecta con el plano siguiente. El collage contextualiza; la función de la app se demuestra con captura real.

Para el flujo habitual usa capas SVG, PNG, formas y recursos permitidos en Remotion. Diseña recorte, contorno, sombra y textura sin destruir la lectura. Anima entradas con causa, orden de capas y reposo; guarda tiempo, posición, escala y rotación editables. Mantén el formato de la pieza y su sonido; no heredes automáticamente los 5 s / 24 fps del ejemplo externo.

Si faltan recursos, usa [video-recursos-visuales](../video-recursos-visuales/SKILL.md) respetando las restricciones del usuario, o crea formas propias. Una imagen raster IA solo es necesaria si mejora el recurso; usar la herramienta de imagen disponible y conservar el archivo original. No afirmar que Claude tiene acceso a imagegen de Codex.

El [original gbro](../../../Biblioteca_Estilos_IA/Fuentes_Comunidad/gbro-collage-broll/SKILL.md) queda para una petición explícita de su pipeline generativo: exige confirmaciones de metáfora y estática, dependencias y una API facturable. Revisar su compatibilidad con el modelo vigente antes de usar scripts. La ruta local por capas es independiente y no consume esa API ni obliga a adoptar sus checkpoints.

Revisa metáfora, contornos, superposiciones y ritmo al tamaño final. Integra mediante [remotion-produccion](../remotion-produccion/SKILL.md), conservando fuentes y procedencia. Entrega capas editables y una revisión audiovisual si la producción/exportación forma parte del encargo.
