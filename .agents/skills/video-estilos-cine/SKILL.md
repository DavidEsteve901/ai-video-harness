# Cine programado y estilos

Consulta [el índice original de estilos](../../../Biblioteca_Estilos_IA/Fuentes_Comunidad/lemo-opuscar/styles/README.md) y [la receta local](../../../Biblioteca_Estilos_IA/02_RECETAS_ESTILOS.md). Hay 51 estilos de la biblioteca; OPUSCAR 98 es otro catálogo de ejemplos. No sumarlos ni asumir que sus 98 películas son recursos para nuestros vídeos.

Elige por función narrativa y material. Para una demo prioriza legibilidad y autenticidad; para un remate puede servir una estética más expresiva. Si el usuario ya eligió un estilo, trabaja sobre él. Si no, compara brevemente unas alternativas pertinentes y decide una cuando el encargo permita avanzar.

Lee solo `styles/<estilo>/STYLE.md` y las guías [DIRECTOR](../../../Biblioteca_Estilos_IA/Fuentes_Comunidad/lemo-opuscar/DIRECTOR.md) y [TECHNIQUE](../../../Biblioteca_Estilos_IA/Fuentes_Comunidad/lemo-opuscar/TECHNIQUE.md) necesarias. Define paleta, trazo, textura, cámara, ritmo y sonido. Conserva ese tratamiento editable; no copies el argumento o la película de ejemplo.

Para un plano dentro de un montaje existente se puede implementar el tratamiento en Remotion. Para una película con el pipeline Lemo hay que obtener la biblioteca ejecutable y revisar requisitos por estilo en una copia local. Los documentos aquí archivados no permiten dar por instalado su plugin ni afirmar que sus renders funcionan en este equipo.

Su README distingue código MIT, películas de ejemplo CC BY 4.0 y recursos de terceros con condiciones propias. Mantén atribución y procedencia cuando corresponda. Usa las voces locales y material autorizado del proyecto. Verifica los frames donde la textura, cámara o efectos podrían tapar interfaz o texto; revisa audio y archivo final si se exporta.
