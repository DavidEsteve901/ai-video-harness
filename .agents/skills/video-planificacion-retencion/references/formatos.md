# Elegir formato y adaptar el mismo concepto

Estas son decisiones editoriales de partida, no límites técnicos de las plataformas. Comprueba las especificaciones actuales si el encargo depende de una duración máxima, una función de publicación o un tipo de archivo.

## Diferencias que cambian el plan

| Formato / uso | Pregunta de planificación | Apertura útil a considerar | Desarrollo | Cierre |
| --- | --- | --- | --- | --- |
| TikTok breve en feed | ¿Qué entiende alguien que no conoce al creador? | Acción, resultado o situación reconocible | Una idea con prueba o giro | Recompensa; continuidad o CTA solo si aporta |
| Reel breve | ¿Qué hace que la pieza sea entendible y merezca compartirla o conservarla? | Imagen legible y contexto suficiente | Demostración, situación o pequeña historia | Remate coherente con la intención |
| YouTube Short | ¿Se entiende de inmediato por qué continuar? | Promesa visible y primer avance | Resolver una pregunta o enseñar una transformación | Resolver dentro del Short; enlace a otra pieza si procede |
| YouTube largo por búsqueda | ¿Qué tarea o duda viene a resolver? | Resultado y alcance claros | Pasos, explicación, errores y comprobación | Tarea resuelta y siguiente paso pertinente |
| YouTube largo por descubrimiento | ¿Por qué elegirlo y qué interés sostiene después? | Apertura coherente con título y miniatura | Progresión, evidencia y capítulos | Cumplir la promesa principal |
| Demo de producto | ¿Qué acción prueba realmente la función? | Resultado real o contraste verificable | Enseñar la acción con contexto | Beneficio concreto, sin inflar promesas |
| Recorte de un vídeo largo | ¿Qué contexto se pierde fuera de la pieza original? | Reintroducir sujeto y situación | Tramo autónomo; eliminar referencias huérfanas | Respuesta completa a la promesa del recorte |

Las diferencias entre TikTok, Reels y Shorts de esta tabla orientan la creatividad; no describen tres algoritmos con fórmulas fijas. En YouTube conviene separar elección, permanencia y satisfacción; ver [YT-S](fuentes.md).

## Plantillas de tiempo para empezar, no para rellenar

### Ejemplo: demo breve de unos 18 segundos

| Tramo estimado | Función |
| --- | --- |
| 0–2 s | Enseñar el resultado o una situación que se reconozca |
| 2–5 s | Establecer qué acción se va a demostrar |
| 5–14 s | Acción visible, con sus pasos importantes |
| 14–18 s | Confirmar resultado y rematar |

Acorta o amplía al medir el material. Si la acción tarda más, conserva su comprensión o cambia la promesa; no ocultes pasos necesarios para que quepa.

### Ejemplo: tutorial largo de unos ocho minutos

| Tramo estimado | Función |
| --- | --- |
| Inicio breve | Resultado, destinatario y alcance |
| Preparación | Requisitos mínimos para poder seguirlo |
| Desarrollo principal | Pasos en orden; comprobar cada hito |
| Caso práctico | Ver el proceso funcionar completo |
| Fallos y límites | Resolver las dudas más previsibles |
| Cierre | Confirmación y siguiente tarea si tiene sentido |

No uses una intro de 30 segundos porque Analytics mida esa marca: una cosa es el informe y otra la estructura. No conviertas el tutorial en una cadena de preguntas sin respuestas.

## Una idea, varias versiones

Idea de ejemplo: **preparar un escritorio con varias aplicaciones**.

- **Short/Reel/TikTok:** una demostración o situación por pieza. La imagen debe probar lo prometido; el formato no necesita explicar toda la configuración.
- **YouTube tutorial:** explicar configuración, condiciones y verificación. Si solo hay un clip corto del resultado, faltan grabaciones; no rellenar minutos con el mismo plano.
- **Pieza narrativa:** contar qué problema había, qué se intentó y qué cambió, usando hechos del usuario.
- **Animación explicativa:** visualizar las relaciones y añadir la demo real como evidencia cuando se trate del producto.

Adapta apertura, texto, encuadre y cantidad de contexto. No publiques automáticamente el mismo montaje recortado en todas las plataformas.

## Decisiones antes de pedir recursos nuevos

1. ¿Se puede cumplir la promesa con el material existente?
2. ¿Qué plano o voz falta exactamente y cuánto se necesita?
3. ¿Una anotación o un rótulo resuelve la necesidad sin otra grabación?
4. ¿Qué debe conservarse al reencuadrar: cara, cursor, interfaz, subtítulo o acción?
5. ¿La pieza se entiende con subtítulos y también tiene una mezcla adecuada si se escucha?

Para más estructuras de terceros, consulta el [índice de originales](../../../../Biblioteca_Planificacion/SKILLS_COMUNIDAD.md). Usa sus patrones como opciones y conserva el formato elegido por el usuario.
