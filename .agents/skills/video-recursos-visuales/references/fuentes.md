# Dónde buscar recursos visuales

Fuentes consultadas el **20 de octubre de 2026**. Son puntos de búsqueda, no una aprobación automática de cada archivo. Al elegir un recurso, abrir su ficha y comprobar las condiciones aplicables en ese momento. No hacen falta integraciones ni claves API para usar el flujo de búsqueda web disponible.

| Necesidad | Fuente | Qué aporta y qué comprobar |
| --- | --- | --- |

| Fotos, ilustraciones, clips o GIFs | [Pixabay](https://pixabay.com/) y [resumen de licencia](https://pixabay.com/service/license-summary/) | Varios formatos bajo sus condiciones. Comprobar que el resultado pertenece al catálogo pertinente y no a un anuncio o enlace externo. |

## Uso práctico de las fuentes

Para stock genérico suele ser más fácil encontrar una acción utilizable en un banco de vídeo que en una búsqueda de memes. Para una reacción concreta, buscar personaje + emoción o gesto puede dar resultados más precisos. Si la identidad del personaje no es esencial, una reacción distinta puede resolver el mismo remate con mejor encuadre o disponibilidad; explicarlo al elegir.

El buscador de imágenes permite descubrir candidatos; la selección final debe apuntar a la página del recurso, no a una URL de miniatura o un resultado de Google. Una URL temporal de descarga puede servir para obtener el medio, pero no sustituye la página de procedencia en el registro.

## Condiciones sin bloquear el trabajo

Para cada seleccionado basta registrar la condición observada, el enlace que la acredita, la fecha de consulta y la atribución necesaria. No inventar una etiqueta «sin copyright». Si no se puede aclarar el uso de un candidato, dejarlo como pendiente y resolver la escena con otra opción cuando sea posible. No presentar esa incertidumbre como un impedimento para todas las escenas.

No copiar una marca de agua y taparla para simular otro origen, ni eludir restricciones de acceso. Un enlace que pide cuenta o una fuente que no puede revisar la herramienta se registra como tal; se puede seguir buscando en fuentes accesibles.
