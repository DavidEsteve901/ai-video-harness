# Consultas y selección según la escena

Usa esta referencia al construir consultas o comparar candidatos. Los ejemplos son criterios de búsqueda, no recursos que ya se hayan encontrado o descargado.

## De la intención a una consulta

| Necesidad | Buscar | Revisar al abrir |
| --- | --- | --- |
| Reacción graciosa de sorpresa | `[personaje o tipo de persona] surprised reaction close up gif`, `reacción incredulidad primer plano` | Gesto visible, inicio útil, duración y tono de la reacción |
| Foto para un chiste con flecha | `[personaje] funny expression portrait`, `[personaje] awkward pose photo` | Qué señalará la flecha y si el chiste se entiende con la imagen real |
| Situación cotidiana | `frustrated person laptop desk video vertical`, `hands connecting laptop monitor close up` | Que ocurra la acción buscada, no solo alguien sentado ante un ordenador |
| Plano de apoyo para una explicación | `[acción concreta] close up stock footage`, `site:pexels.com/video/ [acción]` | Acción legible, posibilidad de recorte y continuidad con el resto |
| Elemento recortable | `[objeto] transparent png official`, `[objeto] svg Wikimedia Commons` | Transparencia real, fuente y si el estilo encaja con la composición |
| Un meme concreto | `[nombre del meme] original reaction`, `site:tenor.com [gesto]`, `site:giphy.com [personaje] [gesto]` | Que sea esa variante y no otra emoción con el mismo personaje |
| Captura o identidad de una marca | `[nombre] official media press assets` | Fuente oficial, versión correcta y uso pertinente en la escena |

Usa la orientación como criterio de selección, no como límite ciego: un horizontal con sujeto centrado puede funcionar en vertical; un vertical con el gesto detrás de los botones puede no servir. No envíes rutas locales, datos privados o notas internas como parte de una consulta; traduce la necesidad a términos públicos.

## Comparar por lo que cambia la decisión

1. **Sentido:** ¿la imagen expresa la idea o solo comparte palabras con la búsqueda? Una imagen de un robot no demuestra que un asistente organice ventanas.
2. **Acción y lectura:** ¿se entiende dentro del tiempo disponible? Buscar un saludo no se resuelve con un GIF donde el saludo empieza al final de un ciclo largo.
3. **Tono:** ¿es absurdo, elegante, cotidiano, emotivo o serio como pide el vídeo? Una reacción exagerada puede servir para un meme y romper un tutorial sobrio.
4. **Encuadre:** ¿sobreviven cara, manos, objeto y dirección de la mirada al recorte? Reservar espacio para la flecha o rótulo que ya contempla el plan.
5. **Continuidad:** ¿la nueva imagen se conecta con la anterior por acción, mirada, forma, color o contraste intencional? Un contraste brusco puede ser el chiste; debe tener propósito.
6. **Preparación real:** ¿hay archivo accesible y condiciones compatibles, se ha revisado su contenido y alcanza la calidad necesaria? Valorar la calidad para su función, no por el número de píxeles aislado.

No hace falta asignar una puntuación numérica inventada. Al decidir, explica el criterio que hizo ganar al elegido y el límite relevante. Los candidatos débiles se descartan; no se incluyen para completar un número fijo de opciones.

## Ejemplos del proyecto

### Foto de Tony + flecha + app

La ficha `IDEA-001` pide una comparación ridícula que sugiera «ese eres tú». Primero revisa las fotos compartidas de Tony. Si no hay una expresión adecuada, busca por gesto cómico o pose, no solo `Tony Stark wallpaper`.

Una imagen puede servir si la cara se lee en móvil, queda sitio para señalar al personaje o la demo y la comparación se entiende al unir ambos planos. Un wallpaper con mucha armadura y una cara diminuta puede ser temáticamente correcto y fallar como chiste. Una imagen reconocible no es automáticamente el mejor candidato.

No inventes que una foto concreta sonríe o grita antes de abrirla. Si el candidato externo no se puede usar en ese contexto, continúa buscando una alternativa o aprovecha el material existente.

### Fotos de Tony intercaladas con el lanzamiento

`IDEA-002` necesita imágenes que hagan avanzar la asociación: atención → control/acción → satisfacción, por ejemplo. Esa progresión es una propuesta editorial, no una descripción de tres fotos ya existentes. Revisa las imágenes reales y elige las que permitan construirla, ajustándola si aparece una combinación mejor.

La demo del lanzamiento sigue siendo real. Un montaje de stock de un escritorio futurista no sustituye el resultado de la app. No busques diez fotos de poses iguales si la alternancia solo necesita dos expresiones distintas.

### Explicación seria para YouTube

Una escena sobre conectar un monitor requiere ver el cable o la conexión y el cambio de entorno. Una persona mirando su portátil sirve solo para contextualizar, no para demostrar el proceso. Si se pide un tono limpio, no introducir memes porque existan en la biblioteca.

### «Solo estos archivos»

Trabaja con los archivos permitidos. Si falta una reacción, se puede resolver con pausa, rótulo, recorte o animación que encaje, sin abrir una búsqueda web ni añadir imágenes externas. La falta de un recurso no obliga a abandonar la escena.

## Cuándo parar o cambiar de enfoque

Al encontrar un recurso revisado que cubre el hueco, termina esa búsqueda. Una alternativa merece la pena si cambia el tono, la composición o la facilidad de uso, no por ofrecer otra URL parecida.

Si solo aparecen resultados flojos, concreta el gesto/acción, prueba el otro idioma o una fuente distinta. Si sigue faltando la acción exacta, reconsidera el recurso: una foto + zoom, una animación de Remotion o un plano propio pueden resolver mejor la escena. Declara el cambio y conserva la intención del usuario.
